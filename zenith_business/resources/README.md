# Resources

Static assets bundled with the application.

## Logo

The home screen looks for **`logo.png`** in this directory. If present, it is
displayed on the branded start screen (scaled, aspect-ratio preserved). If
absent, a clean placeholder container is shown instead.

The logo is intentionally **not** committed yet (Prompt 01 §14, §35): no
permanent Zenith logo is invented at Stage 01, and no third-party artwork is
used. Drop the final `logo.png` here later — no code or layout changes are
required.
